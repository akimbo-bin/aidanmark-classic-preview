01 Oscillator-Level Inverse Synthesis

solo capstone / Python, PyTorch, librosa, REAPER

A machine-learning pipeline that takes a short recording and predicts oscillator-level parameters for an editable Xfer Serum 2 preset. I wrote the data generation, mel-spectrogram processing, model training, and preset packaging.

Result: 193,283 labelled training examples from 18 wavetables; 97.4% top-1 accuracy on wavetable classification. It is not a measure of complete sound recreation.

02 Campus Delivery Robot

solo build / ROS2, C++, Python, Jetson Orin Nano, Teensy 4.1

An indoor delivery robot that maps its surroundings and drives to destinations. High-level navigation runs on a Jetson; a Teensy handles the motor hardware. I wrote firmware and ROS2 nodes for serial communication, sensor integration, odometry, PID control, and LiDAR SLAM.

Hardware test: Mapped the second floor at MacEwan University.

03 Sometimes Aliens Are Not Your Friends

solo game / JavaScript, WebGL2, GLSL

A 3D game in the browser built without a game engine. It has handwritten shaders, OBJ loading, a scene and camera system, object pooling, spatial-hash collisions, frustum culling, and a light budget.

Source code on GitHub

04 Zero Trust Security Review

client / team work / Proxmox, Active Directory, AD CS, IIS, mTLS

Worked with a team on a security assessment for Universal Rail Systems. We evaluated east-west traffic and built a virtualized proof of concept for identity-based access between internal services. My work included networking, Active Directory, certificates, reverse proxies, and policy hardening.

Delivered: Technical recommendations and a report to the client.

05 Heaterfy

team project / Python, PyTorch, scikit-learn, Spotify API

A playlist recommendation system using audio features, metadata, genre embeddings, and clustering. I led development of the 16-dimensional genre representation, Spotify connection, Streamlit interface, and evaluation.

Classroom evaluation: Twelve listeners rated recommendations an average of 83/100.
