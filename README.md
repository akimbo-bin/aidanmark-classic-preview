# Aidan Mark - handwritten homepage preview

This is an **independent preview**, not the production aidanmark.dev website.

Live preview: https://akimbo-bin.github.io/aidanmark-classic-preview/

The three pages are hand-authored HTML 4.01 (Strict) and CSS 2-era styling:
- `index.html` - the personal home page, with the original ASCII name intact.
- `projects.html` - project notes and links.
- `resume.html` - technical background and résumé.
- `style.css` - the single period-style stylesheet.

No JavaScript, framework, build system, CSS Grid/Flexbox, animation, gradients, modern cards, or external resources. The old proprietary Apercu font is not published; the pages use a system Courier monospace instead.

The long original ASCII name intentionally scrolls horizontally inside its own area on narrow displays, rather than being resized with post-2007 responsive CSS.

Only update the preview repository until the design is personally approved. Never deploy this to the production site as part of preview work.
