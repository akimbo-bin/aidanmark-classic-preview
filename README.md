# Aidan Mark - Classic Portfolio Preview

This is the independently hosted HTML/CSS preview of the earlier classic-style portfolio, kept separate from the live site.

## Edit the site

- `index.html`: Homepage with the original ASCII-art name.
- `projects.html`: Portfolio project descriptions.
- `resume.html`: Skills and background.
- `style.css`: Green/off-white theme and layout.

No JavaScript, build system, or generated framework files. GitHub Pages serves these files directly from the `main` branch root.

The original local version used Apercu Mono Pro, a proprietary font. The public preview omits that font and falls back to Courier; the original font remains on the owner's PC.

**Please keep new changes limited to the preview repo until they have been reviewed.** Do not infer that this repository is the production `aidanmark.dev` site.
