A machine learning system that analyzes an audio sample and generates a playable synthesizer preset that recreates the sound.


Built as a solo university capstone project, a model predicts oscillator-level parameters for Xfer Serum 2 directly from audio, producing real presets that can be loaded, played, and refined. The system demonstrates that audio-to-parameter inference is feasible at scale, while revealing the fundamental limits of parameter-based synthesis.
